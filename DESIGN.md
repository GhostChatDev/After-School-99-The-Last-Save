# After School ’99 — visual direction

A warm late-90s desktop wrapped around a crisp, modern play area. This first milestone is a vertical slice, not the complete campaign.

- Background: `#11172c`; surface: `#1c2440`; border: `#44506b`
- Text: `#f9eed6`; muted: `#b5c1ca`; accent: `#ffd282`; success: `#78e1c1`; danger: `#ff938b`
- Font: system sans for UI, monospace for labels and game details. Body 16px; headings 24/36/48px; numbers use tabular figures.
- Spacing: 4, 8, 12, 16, 24, 32px. Radii: 8px, 16px.
- Components: desktop title bar, story panel, mission HUD, canvas, direction pad, status panel, action buttons.
- The board uses original drawn shapes, a warm monitor glow, clearly numbered packets and a visibly marked exit. Controls sit below the board on narrow screens.
